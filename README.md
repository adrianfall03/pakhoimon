# 怪兽探险 · MonsterQuest（澪原物语）

一个**纯前端、零依赖**的浏览器宝可梦风格 RPG。打开 `index.html` 即可游玩——无需构建、无需联网。

![规模](https://img.shields.io/badge/怪兽-232-green) ![NPC](https://img.shields.io/badge/NPC-132-blue) ![地图](https://img.shields.io/badge/地图-64-orange)

## 内容规模

| 项目 | 数量 |
|---|---|
| 怪兽（含进化形态） | **232** 只（其中 116 个进化关系、12 只传说、3 只幻之怪兽） |
| 招式 | 76 种（18 属性 + 状态/能力变化） |
| 道具 | 45 种（精灵球 / 回复 / 进化石 / 强化 / 关键道具） |
| NPC | **138** 位（含 72 名可对战训练师、8 位道馆馆主、四天王、冠军、反派首领、鼬鼠博士、劲敌） |
| 地图 | 64 张（10 座城镇 + 道路 + 洞窟 + 道馆/商店/中心/民宅等室内） |
| 主线 | 12 章长篇剧情，横跨 6 大地区 |

## 玩法

- **探索**：方向键 / WASD 在瓦片地图上行走，进出建筑、踩高草丛遇敌、跳下断崖。
- **回合制战斗**：完整伤害公式、18 属性克制、击中要害、STAB、状态异常（灼伤/中毒/剧毒/麻痹/睡眠/冰冻）、六维能力升降、防护屏障、先制度。
- **捕捉**：多种精灵球（含必中的大师球），采用经典摇晃判定公式。
- **成长**：经验/升级/学新招式、4 种经验曲线、性格、个体值、努力值、三种进化方式（等级 / 进化石 / 亲密度）。
- **队伍 / 背包 / 图鉴 / PC 储存 / 商店 / 训练家卡**：完整菜单系统。
- **存档**：localStorage 自动序列化。

## 运行

```bash
# 方式一：直接用浏览器打开
open index.html

# 方式二：本地静态服务器
npm run serve   # http://localhost:8123
```

## 开发命令

```bash
npm run gen      # 重新生成全部内容数据（确定性，seed 固定）-> js/data/*.js
npm run verify   # 无头验证：模拟浏览器加载全部脚本并真实驱动玩法，39 项断言
npm run balance  # 数值模拟：用真实伤害公式跑全主线练级与各道馆胜率
npm run serve    # 启动本地静态服务器
```

### 数值与平衡

等级与种族值是一条**连贯的成长曲线**（`tools/lib/gen-world.js` 的 `LEVELS` 表），不再用脱节的公式：

- **道路野怪 ≤ 玩家等级**：1 号道路 Lv3-5，玩家起始 Lv5 即领先；之后每条道路 ~+3 级，平滑爬升至联盟。
- **道馆 Lv7→13→19→25→31→37→44→50**，馆主只比所在道路高 1-2 级；四天王 52-59，冠军 61-66。
- **种族值档位随进度解锁**（`okCat`）：早期道馆只出常见种，避免一开局就遇到进化后的稀有种（种族值 480+）碾压。
- **自我追赶的经验机制**（`Species.expYield`）：击败高于自己等级的对手获得额外经验、练过头则锐减，让任意规模的队伍都自动贴近内容等级；配合**现代全员共享经验**（`awardExp`），多属性队伍不会因分摊而掉队。
- 野怪按等级**解析进化形态**（`Species.dexForLevel`），高级区域出现已进化的同族。

`npm run balance` 会输出"落后 N 级胜率"与逐道馆胜率，作为数值回归基线。

## 架构

内容由**确定性生成器**批量产出（保证"上百"规模且数据连贯），引擎与系统为手写：

```
tools/
  generate.js          编排器：输出 js/data/*.js（浏览器全局 window.MQ.*）
  lib/
    rng.js             确定性随机数（mulberry32）
    types.js           18 属性 + 完整克制表
    names.js           中文怪兽名词素库
    gen-moves.js       招式生成
    gen-monsters.js    怪兽 + 进化链 + 能力值分配 + 招式表
    gen-items.js       道具目录
    gen-world.js       地图拓扑 / 传送 / 遭遇表 / NPC / 训练师队伍
  verify.js            无头玩法验证
  serve.js             零依赖静态服务器

js/
  data/                生成的数据（怪兽/招式/地图/NPC/...）+ 手写的 story.js
  core/                util（索引/克制/事件）· species（实例/升级/进化）· game（状态机/主循环）
  engine/              input · render（瓦片 + 程序化怪兽精灵）· ui_primitives（转场/提示/对话框）· world（移动/碰撞/遭遇）
  systems/             battle（回合制引擎）· npcs（交互/训练师/徽章）· save（存读档）
  ui/                  ui（菜单/背包/图鉴/PC/商店）· title（标题/开局）
  main.js              启动引导
```

### 美术风格（GBA 像素风）

参照经典 GBA 宝可梦画风，全部由 Canvas **程序化绘制**（零美术资源）：

- **瓦片**：草地/高草/树木/泥土路/水/花/砖墙/瓦顶/木门/洞窟/木地板等均为 16 位像素风，按坐标哈希取纹理变体，预烘焙到离屏 canvas 缓存后再 blit（性能）；水面逐帧动画。
- **角色**：训练师像素小人（帽子/头发/脸/上衣/裤子/鞋分层），四方向 + 行走帧，右向由左向镜像；主角红帽，各类 NPC 调色板各异。
- **怪兽**：以 dex 为种子程序化绘制，带**深色描边 + 赛璐珞明暗分区 + 高光眼睛 + 耳角/翅膀/尾巴等体型变化**，每只独一无二。

### 关键设计

- **零资源**：所有瓦片、角色、怪兽均在 Canvas 上程序化绘制，无需任何图片素材。
- **战斗事件模型**：一个回合被**同步模拟**为有序事件序列——状态变更立即应用以保证分支判定正确，而显示更新（血条/震动）作为回放事件延迟呈现，使动画与文字同步。
- **剧情解耦**：主线里程碑按条件（徽章数 / 旗标）首次满足时触发，与严格顺序解耦，支线（反派篇）不会卡死叙事。

## 主线梗概

少年从新叶镇的鼬鼠博士处获得初始伙伴，踏上收集八枚徽章、挑战精灵联盟的旅途。途中逐渐揭开「黯灭组织」企图用「虚空碎片」唤醒**虚空之兽**、令永夜笼罩澪原的阴谋。击败组织首领、登顶成为冠军后，真正的终章——天空神殿之上与觉醒的虚空之兽的决战——才刚刚开始。
